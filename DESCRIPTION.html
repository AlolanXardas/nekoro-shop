A shop for buying and selling with the server, and a market for trading between players.
Made for my Nekoro Pokemon modpack, but it works with any mods.

Required on the client and the server.

Features

Server shop

  • Buy from the server and sell to it at set prices.
  • Operators change the offers in game with the Edit button, or in the config.
  • Every offer can have a daily limit for each player and for all players together.
  • The day follows the clock of the computer the server runs on.

Player market

  • Players list items at their own prices.
  • Offers stay for 7 days by default. After that only the seller sees them and can take the items back or list them again.
  • The frame of an offer shows how much time it has left.
  • The config sets a tax on sales, the number of offers per player, and items that can't be listed.

Money

  • Every player has a balance. The name and short form of the money are set in the config, Nekoro Coins (NC) by default.
  • Nothing gives money by default. How players earn it is up to the world or modpack.
  • With Nekoro Coins installed, the default server shop buys and sells coins, so they can be changed into money and back.
  • /balance and /pay for players, can be turned off.
  • /nekoroshop balance, add, remove and set for operators.

Shop window

  • Search by name, sort, and filter by a price from and to.
  • Categories come from the creative tabs, and you can add your own in the config.

Other features

  • Shop Catalog: Opens the shop from anywhere with a right click.

More information

Config

  • All files are in config/Nekoro/Shop/ and every option is explained in the file.
  • shop.json: the money, the start balance, commands and the market.
  • server_shop.json: what the server sells and buys.
  • categories.json: the categories of the shop window.
